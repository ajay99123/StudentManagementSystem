# Student Management System

A beginner-friendly Student Management System developed using **Java, JDBC, and MySQL**.

## Version

**v2.0 – Final**

## Features

- Add Student
- View All Students
- Search Student by ID
- Update Student
- Delete Student
- Input Validation
- MySQL Database Integration
- JDBC Connectivity

## Technologies Used

- Java
- JDBC
- MySQL
- IntelliJ IDEA
- Git & GitHub
